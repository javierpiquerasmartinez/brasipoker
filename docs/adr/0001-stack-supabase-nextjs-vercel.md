# Supabase + Next.js + Vercel como base del MVP

Asumimos la propuesta del PRD: Next.js + Tailwind como frontend PWA, Supabase como backend (Postgres, Auth y Realtime para el panel del Organizador en vivo) y Vercel como hosting. Elegido por coste inicial bajo, velocidad de desarrollo y por ser la vía más corta al flujo "Enlace → página pública → registro sin cuenta". Decisión reversible a medio plazo solo con coste de migración de datos; congelada hasta validar el MVP.
